# Reglas permanentes del proyecto

- Cuando se agreguen tareas, retos, prácticas u otras actividades con material extenso, presenta el contenido en botones o secciones desplegables para no ocupar demasiado espacio en la planeación.
- Dentro del desplegable, separa claramente los recursos (por ejemplo, script, instrucciones y preguntas) y agrega botones de copia cuando el contenido esté pensado para usarse en VS Code u otra herramienta.
- Conserva el diseño responsive y verifica que el contenido desplegable no provoque desbordamiento horizontal.
- Después de cada cambio solicitado en este proyecto, implementa y verifica la modificación localmente, crea un commit que incluya únicamente los archivos pertinentes y publícalo en la rama `main` de GitHub (`origin/main`).
- Al finalizar, informa el resultado de la verificación y el identificador del commit publicado.
