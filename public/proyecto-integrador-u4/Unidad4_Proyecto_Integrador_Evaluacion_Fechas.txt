Total: 100 % de la evaluación del proyecto integrador.

AVANCE 1 — 10 %
Entregar por correo una propuesta con: idea, problema, usuarios y objetivo; arquitectura preliminar y diagrama de IA, cliente y servidor MCP, aplicación y servicios; modelo de datos preliminar de al menos dos bases; flujo de pago o suscripción; herramientas MCP propuestas con su propósito; y repositorio GitHub creado con acceso para revisión. Adjuntar la propuesta o enlazarla en el repositorio.

AVANCE 2 — 10 %
Mostrar aplicación parcialmente funcional con autenticación, al menos dos bases conectadas, al menos tres herramientas MCP funcionando, primer flujo del chatbot, pago integrado en sandbox o modo de pruebas y README inicial. Subir código y evidencia reproducible al repositorio; incluir instrucciones y enlaces para la revisión.

AVANCE 3 — 10 %
Presentar versión casi final desplegada en staging o producción; al menos seis herramientas MCP; chatbot que use contexto real autorizado del usuario y la aplicación; flujo completo de pagos en modo prueba; seguridad básica, pruebas y documentación. Preparar presentación y demostración. Incluir enlaces, evidencia y pasos para revisar.

ENTREGA FINAL — 70 %
Aplicación desplegada en producción y funcional con todos los requisitos del documento de descripción, repositorio GitHub, README y documentación, URL de producción o enlace de descarga funcional, evidencia de pruebas y demostración presencial. Demostrar las dos bases, autenticación y roles, chatbot, herramientas MCP y flujo de pago en modo prueba, además de explicar cómo se configura el proveedor real. El repositorio y los enlaces deben estar disponibles para el docente.
